# game305-kanca

GAME305 Project and Portfolio I grup projesi: sonunda boss dövüşü olan bir 2D platform oyunu. Oyuncunun kendisiyle konuşan bir kılıcı var. Kılıç fırlatılıp işaretli noktalara saplanıyor ve oyuncu ona doğru çekilip ivmeyle fırlıyor.

- **Motor:** Unity 6000.3.26f1 (6.3 LTS), URP 2D
- **Kontrol:** klavye ve fare
- **Görsel:** piksel art karakter, elle boyanmış katmanlı arka plan
- **Hedef platform:** Windows ve tarayıcı (itch.io)
